# School Website Chalane Ki Poori Guide (Hinglish)

Yeh guide un logon ke liye hai jo school ki website admin panel se
chalate hain. Koi technical knowledge ki zaroorat nahi hai.

> **Zaroori baat:** Admin panel ke saare **field ke naam English me hain**
> (jaise "Section title", "Primary image"). Is guide me bhi wahi English naam
> likhe hain, taaki aap screen par exactly wahi dhoondh sakein. Samjhaane wali
> baatein Hinglish me hain.

## 1. Sabse pehle

Panel me jo bhi hai, woh in **5 cheezon** me se ek hai. Yeh samajh gaye to
baaki sab apne aap samajh aa jayega.

### 1.1 Website

Ek school = ek website. Panel me ek se zyada bhi ho sakti hain — senior wing,
junior wing, doosra campus. Har ek ka apna logo, colour, pages aur content
hota hai. **Ek website me kuch bhi likhoge to doosri me kabhi nahi dikhega.**

Screen me sabse upar building icon ke paas jis website ka naam likha hai,
**abhi aap wahi edit kar rahe ho.**

> **Sabse badi galti yahi hoti hai** — galat school me type karte reh jana.
> Kaam shuru karne se pehle 2 second lagakar naam check kar lijiye.

### 1.2 Design

Design se home page ka **dhaancha** badalta hai — banner kahan hoga, heading
kitni badi hogi, menu kahan aayega. Total **7 design** hain.

**Design badalne se aapka content kabhi delete nahi hota.** Sirf layout badalta
hai. Jaise photo wahi rehti hai, sirf frame badal jaata hai. Pasand na aaye to
turant wapas badal do.

### 1.3 Section

Home page **30 blocks** se banta hai, inhe section kehte hain — banner,
principal ka message, photo gallery, news list, waghairah.

Har section ko alag-alag:
- **on/off** kar sakte ho
- **upar-neeche** kar sakte ho
- **bhar** sakte ho

**Jo section off hai ya khaali hai, woh site par bilkul dikhta hi nahi.** Na
koi khaali jagah, na "coming soon" likha aata hai. Visitor ko pata bhi nahi
chalega ki woh section exist karta hai.

Aap 30 me se sab use nahi karoge. Zyadatar school **8 se 12** use karte hain.
Yeh bilkul theek hai.

### 1.4 Content list

Kuch cheezein baar-baar add hoti hain — news, events, departments, staff.
Ye sidebar me **Content** ke neeche apni alag list me rehti hain.

**Fayda:** News list me ek news add kiya, to woh home page par bhi aayega,
news page par bhi, aur menu se bhi khulega — teeno jagah alag-alag kaam nahi
karna padega.

### 1.5 Setting

Jo cheez poori website par lagti hai — colour, upar wali scrolling notice
patti, popup, hover effect — woh **Site settings** me hai.

## 2. Login

### Login karne ka tarika

1. Browser me apna **admin address** kholiye (IT wale ne diya hoga)
2. Apna **email** aur **password** daaliye
3. **Sign in** dabaiye

Password bhool gaye? Kisi administrator se **User accounts** me jakar reset
karwa lijiye.

### Sidebar (baayin taraf ka menu)

**School website — rozana ka kaam**

| Naam | Kis kaam ke liye |
|---|---|
| **Workspace** | Panel ka pehla page. Shortcuts aur summary. |
| **Branding** | Logo, colour, school ka naam, address, phone, design |
| **Home page** | Home page ke 30 sections |
| **Pages** | About, Admission, Facilities, Contact waghairah |
| **Contact inbox** | Visitors ne jo enquiry bheji |
| **Navigation** | Upar wala menu bar |

**Content — ek jagah bharo, kai jagah dikhega**

| Naam | Kis kaam ke liye |
|---|---|
| **Media library** | Saari uploaded photos aur files |
| **News & notices** | Circular, result, announcement |
| **Events** | Sports day, annual day, PTM |
| **Departments** | Science, Commerce, Primary Wing |
| **Faculty & staff** | Teachers aur staff, photo ke saath |

**Configuration — ek baar set karo, baar-baar nahi**

| Naam | Kis kaam ke liye |
|---|---|
| **Site settings** | Notice bar, popup, colour, effects, admission |
| **SEO settings** | Google par title aur description |

**Platform — sirf senior admin ko dikhta hai**

| Naam | Kis kaam ke liye |
|---|---|
| **Websites** | Nayi school website banana |
| **Website templates** | Banaye-banaye design |
| **Domains** | Kaunsa web address kaunsi website dikhaye |
| **Page gallery** | Nayi website ko kaunse starter pages milein |
| **User accounts** | Kaun login kar sakta hai |
| **Tenants** | Alag-alag organisation |

### Save karna — bahut zaroori

> **Jab tak neeche wala Save button nahi dabaoge, kuch bhi save nahi hoga.**
> Yahan **autosave nahi hai.** Beech me doosre page par chale gaye to jo
> likha tha woh chala jayega.

**Save dabate hi live website par turant dikh jata hai.** Koi "publish"
button nahi hai, koi waiting nahi hai. Doosre tab me site refresh karo, wahan
change aa chuka hoga.

> **Tip:** Kaam karte waqt live website ko **doosre tab me khula rakho**.
> Panel me upar-daayin taraf wale button se woh khulti hai. Har change ke
> baad us tab me refresh (Ctrl+F5) maar ke dekh lo.

## 4. Home page

**Kahan:** School website → Home page

Yahan 30 sections list me dikhte hain. Har section ke liye aap:

- **on/off** kar sakte ho — off matlab visitor ko nahi dikhega, par aapka
  content safe rehta hai
- **upar-neeche** kar sakte ho
- **Edit** dabakar bhar sakte ho

### 4.1 Har section me ye 4 panel hote hain

Koi bhi section kholo, ye 4 dikhenge:

**1. Content & messaging**
- **Section title** — badi heading jo visitor ko dikhti hai
- **Subtitle** — uske neeche chhoti line (optional)
- **Description** — paragraph likhne ka box. Bold, italic, list, link sab kar
  sakte ho

**2. Call to action**
- **Button text** — khaali chhodo to button nahi aayega
- **Button destination** — button kahan le jaye. Ya to apni site ka page
  (`/admission`), ya poora address (`https://...`)

**3. Section configuration**
- Is section ke apne field. Har section ke alag hain, neeche list di hai.
- Kuch sections me **repeating rows** hoti hain — ek row per course, per
  photo, per staff. **Add row** se add karo, cross se hatao.
- **Advanced JSON configuration** technical logon ke liye hai.
  **Aapko kabhi zaroorat nahi padegi. Ignore karo.**

**4. Media assets**
- **Primary image** — section ki main photo
- **Background image** — poore section ke peeche photo. Uske upar apne aap
  halka safed parda aata hai taaki likha hua padha ja sake

### 4.2 Ek-ek section

Neeche "Fields" matlab **Section configuration** me jo aata hai, aur "Rows"
matlab repeating list.

---

#### 1. Hero Banner
**Kya hai:** home page ke sabse upar ki badi photo. Visitor sabse pehle yahi

> **"Banner pictures carry their own text"** on kar do.
>
> Isse heading, button aur parda hat jayega aur aapka poster **poora,
> bina kata hua** dikhega. Warna site apni heading aapke poster ke likhe ke
> upar chhaap degi aur do heading ek saath dikhengi.

## 5. Pages

**Kahan:** School website → Pages
Home page ke alawa baaki saare pages.

| Field | Kya karta hai |
|---|---|
| **Title** | Heading, aur menu me naam |
| **Slug** | Address. `about` likhoge to `yourschool.edu/about` banega. Chhote akshar, space ki jagah hyphen, koi symbol nahi. |
| **Page type** | Layout tay karta hai (neeche list) |
| **Template key** | Technical. Haath mat lagao. |
| **Excerpt** | Ek line ka summary |
| **Page content (HTML)** | Page ka main content |
| **Menu order** | Chhota number pehle aata hai |
| **SEO title** | Google par heading |
| **SEO description** | Google par neeche ka grey paragraph |

### Page types

| Type | Kya milta hai |
|---|---|
| **About** | Seedha-saada article layout |
| **Admission** | Article + Site settings wali admission details |
| **Facilities** | Facilities ka grid |
| **Messages** | Principal / chairman ke message ka layout |
| **Gallery** | Photo grid |
| **Disclosure** | Board disclosure ki table |
| **Committee** | Committee members ki list |
| **Contact** | Contact details, map, aur enquiry form |
| **Custom** | Khaali page — sab kuch aap likho |

> **Slug badalne se page ka address badal jata hai.** Jisne bookmark kiya tha,
> aur jo link prospectus me chhap chuka hai — sab toot jayega. Ek baar
> shuruaat me tay karo, phir haath mat lagao.

## 6. Content lists

Ye chaar list ek saath **kai jagah** dikhti hain.

### 6.1 News & notices
Circular, result, admission announcement. Har item me headline, summary,
poora text, date aur category.

**Kahan dikhega:** home page (Latest News section), news page, aur news wala
menu link.

**Yaad rakho:** yahan ke items home page section ki rows ko override kar dete
hain.

### 6.2 Events
Sports day, annual day, PTM. Title, date, location, description.
**Kahan dikhega:** home page (Upcoming Events) aur events page. News wala hi
override rule.

### 6.3 Departments
Science, Commerce, Primary Wing. Naam, description, photo.

### 6.4 Faculty & staff
Teachers aur staff — photo, designation, qualification ke saath.

**Photo aur detail chahiye** → yeh use karo.
**Sirf 40 naam ki table chahiye** → home page ka Staff List section use karo.

## 7. Media library

**Kahan:** Content → Media library

Saari uploaded photos aur files ek jagah.

**Upload karna:** Upload dabao → file chuno → poora hone tak ruko.

**Kahin bhi photo lagana:** jahan bhi image field ke paas **Browse** button
dikhe, use dabao aur yahan se chuno.

**Ye hamesha behtar hai** kyunki:
- doosri site ki photo bina bataye gayab ho sakti hai
- apni upload ki hui photo tez khulti hai aur hamesha rehti hai

**Sahi size:**

| Kahan | Size |
|---|---|
| Banner / hero | 1920 × 1080 pixel |
| Section photo | 1600 × 900 |
| Gallery | 1200 × 800 |
| Portrait | 600 × 600 |
| Logo | Lagbhag 300 pixel lamba, transparent background |

File **500 KB se kam** rakhne ki koshish karo. Badi photos se page slow hota
hai, khaaskar mobile par.

## 8. Contact inbox

**Kahan:** School website → Contact inbox

Website ke kisi bhi form se jo bhi aaya — contact page ka form ho ya popup ka
— sab yahan aata hai. Naam, email, phone, subject, message aur date ke saath.

> **⚠ Ye aapko email par nahi bheje jate.** Roz ya har doosre din yahan
> khud aakar dekhna padega, warna enquiry chhoot jayegi.

Site settings me **Enquiry types** bhar doge, to har message me likha aayega
ki woh admission enquiry hai, job application hai, ya feedback — bina padhe
chhaant sakoge.

## 9. Navigation

**Kahan:** School website → Navigation
Website ke upar wala menu.

Har menu item ke liye:
- **Label** — jo shabd dikhega
- **URL** — kahan le jayega (`/about`, ya poora `https://...`)
- **Order** — chhota number pehle (baayin taraf)
- **Parent** — set karoge to dropdown ban jayega

> **Menu chhota rakho.** 9-10 item se zyada hue to menu **doosri line me
> chala jata hai** aur bhadda dikhta hai. Baaki sab dropdown me ya footer me
> daalo.

## 10. Site settings

**Kahan:** Configuration → Site settings

### 10.1 Announcement bar
Har page ke sabse upar ki rangeen patti.

| Setting | Kya karta hai |
|---|---|
| **Notice text** | Kya likha aayega. Kai notice ke beech `\|` lagao: `Admissions open \| Results out` |
| **Label** | Shuru me chhota shabd — "NOTICE", "LATEST". Khaali = kuch nahi |
| **Scroll the text across the bar** | On = chalta rahega, off = ruka rahega |
| **Copies on the strip** | One / two / three / "fill the strip". Chhota notice = one. Lamba notice = fill the strip, warna beech me khaali jagah dikhti hai |
| **Seconds for one pass** | Kitni der me ek chakkar. Zyada number = dheere |
| **Notice bar colour** | Khaali = primary colour |
| **Notice bar style** | Solid, gradient, dark, outline |

### 10.2 Admissions

| Setting | Kya karta hai |
|---|---|
| **Status** | Open, closed, ya opening soon |
| **Enquiry phone / Enquiry email** | Admission pages par dikhta hai |
| **Office hours** | Contact page aur footer me |
| **Prospectus / brochure** | Jo PDF parents download karte hain |
| **Online application link** | "Apply now" button kahan le jaye |
| **Enquiry types** | Ek line me ek. Form par dropdown ban jata hai |

### 10.3 Social and messaging
Facebook, Instagram, YouTube, X, LinkedIn, WhatsApp number.
**Footer aur contact page par icons** ban ke dikhte hain. Poora address paste
karo. Jo nahi use karte woh khaali chhodo.

### 10.4 Appearance and motion

| Setting | Kya karta hai |
|---|---|
| **Logo height (pixels)** | 28 se 160 ke beech. Bada crest header se neeche latak kar banner ke upar aata hai, **header bada nahi hota** |
| **Crest shape** | **Rounded** (gol), **Square** (gol-kinaare wala box), **Original** (sirf artwork, peeche kuch nahi). Agar crest ka apna shape hai to Original chuno |
| **Button colour / style / shape / hover** | Button kaise dikhein aur behave karein |
| **Card hover / Picture hover / Link hover** | Mouse le jaane par kya ho |
| **Hover colour** | Un effects ka colour |
| **Default section entrance** | Scroll par section kaise aayein |
| **Default section background** | Jis section ki apni photo nahi, uske peeche pattern |
| **Fade sections in as the visitor scrolls** | Movement nahi chahiye to off karo |
| **Banner pictures carry their own text** | Banner poora dikhega, upar kuch nahi chhapega. Poster artwork ke liye |
| **Phone and email in the header** | Logo ke bagal me "Call us" / "Mail us". **Ise on hi rakho** — page ke upar phone dikhane ki aur koi jagah nahi hai |
| **Header button** | Header ke button ka text aur link, jaise "Admission Enquiry" |

### 10.5 Opening popup
Site khulte hi jo window aati hai.

## 13. Step-by-step processes

Yahan har kaam **click-by-click** likha hai.

### 13.1 Nayi news / circular daalna

1. Sidebar me **Content → News & notices** kholo
2. Upar **Add** ya **New** button dabao
3. **Headline** likho — jaise `Winter break circular`
4. **Summary** me ek-do line — jaise `School closes from 24 December and
   reopens on 2 January.`
5. **Content / body** me poori detail likho
6. **Date** chuno (jo date dikhani hai)
7. **Category** chuno agar option ho (Circular / Result / Notice)
8. **Save** dabao
9. Doosre tab me website kholo → **Ctrl+F5** dabao
10. Home page par **News & notices** section me sabse upar aa gaya hoga

> Home page ke Latest News section me kuch **nahi** karna hai. Woh apne aap
> yahan se uthata hai.

---

### 13.2 Banner ki photo badalna

**Sirf ek photo lagani hai:**

1. **School website → Branding** kholo
2. **Header / banner image URL** field dhoondho
3. Bagal me **Browse** dabao → Media library khulegi
4. Photo par click karo → woh chun li jayegi
5. Neeche **Save** dabao
6. Website refresh karke dekho

**Slideshow lagani hai (kai photo badalti rahein):**

1. **School website → Home page** kholo
2. **Hero Banner** ke saamne **Edit** dabao
3. Neeche **Section configuration** tak scroll karo
4. **Add row** dabao
5. Row me **Image** field ke paas **Browse** → photo chuno
6. **Image description** me chhota description likho (jaise `Annual day 2026`)
7. Har photo ke liye 4-6 dohrao
8. **Slide change (seconds)** me `5` ya `6` daalo
9. **Save** dabao

**Agar aapke banner poster hain (jinpar pehle se likha hai):**

10. **Configuration → Site settings** kholo
11. **Appearance and motion** me **"Banner pictures carry their own text"**
    on karo
12. **Save** dabao

Ab poster poora, bina kate, bina kisi heading ke dikhega.

---

### 13.3 Gallery **page** me photos add karna

Ye menu wala alag Gallery page hai, home page ki strip nahi.

1. **Content → Media library** kholo → apni photos **Upload** karo
2. **School website → Pages** kholo → list me **Gallery** dhoondho → **Edit**
3. Neeche **Structured page content** tak scroll karo
4. Har photo ke liye **Add** dabao aur row bharo:
   - **Album name** — ek hi naam wali photos ek heading ke neeche group ho
     jati hain, jaise `Annual Day`, `Sports Day`. Khaali chhodoge to sab
     "Gallery" naam ke ek hi heading me aa jayengi
   - **Type** — `image` chuno
   - **Image URL or video embed URL** — **Browse** dabao aur photo chuno
   - **Caption** — photo me kya hai
5. **Save** dabao

**Isi page par video daalni ho:** ek row add karo, **Type** me `video` chuno,
aur browser se copy kiya hua normal YouTube link paste kar do. `watch?v=...`,
`youtu.be/...`, Shorts, Vimeo — sab chalte hain.

### 13.3b Home page ki gallery strip me photos add karna

1. **Content → Media library** kholo
2. **Upload** dabao → apne computer se saari photos ek saath chuno
3. Upload poora hone ka wait karo

5. **Section title** me `Gallery` ya `Campus Life` likho

## 15. Common galtiyan

**News aur Events list home page section ko override karti hai.**
Content → News me article hai to Latest News section ki rows **bilkul ignore**
ho jayengi. List edit karo, section nahi.

**Enquiry email par nahi aati.**
Contact inbox me padi rehti hai. Roz check karo.

**Khaali section poori tarah gayab ho jata hai.**
Na gap, na placeholder. Site par nahi dikh raha matlab ya off hai ya khaali.

**Save dabate hi live ho jata hai.**
Koi draft mode nahi hai, koi preview-phir-publish nahi hai.

**Doosri site se paste ki gayi photo toot sakti hai.**
Woh log photo hata denge to aapke page par caption text dikhne lagega.
**Media library me upload karo aur Browse se chuno.**

**Slug hi address hai.**
Badloge to har purana link toot jayega — bookmark, prospectus me chhapa hua
link, doosri site se aane wale.

**"Allow search engines to index this website" off karoge to Google se gayab
ho jaoge.** Site banate waqt kaam ka hai, launch par on karna bhool gaye to
badi museebat.

**Upar likha hai ki kaunsi website edit ho rahi hai.**
Ek se zyada school hain to type karne se pehle dekh lo.

## 16. Troubleshooting

| Kya dikh raha hai | Wajah | Kya karein |
|---|---|---|
| Photo ki jagah likha hua text | Photo ka address toot gaya | Nayi photo daalo, Media library se |
| Section site par nahi dikh raha | Off hai, ya khaali hai | Home page → on karo / bharo |
| Menu do line me chala gaya | Bahut zyada items | Kuch dropdown me ya footer me daalo |
| Change dikha hi nahi | Save nahi dabaya, ya purana page cache me hai | Save dabao; **Ctrl+F5** (Mac par **⌘+Shift+R**) |
| Home page ka dhaancha achanak badal gaya | Design badal diya gaya | Branding → Home design → wapas set karo |
| Mere poster ke upar heading chhap rahi hai | Banner ko photo samjha ja raha hai | Site settings → **"Banner pictures carry their own text"** on karo |
| Banner dhundhla / feeka dikh raha hai | Hero section par **background image** set hai, jiske upar parda aata hai | Home page → Hero Banner → Media assets → background image **hatao**. Banner ki photo Hero row me ya Branding me daalo, section background me nahi |
| Page ke upar phone number nahi dikh raha | "Phone and email in the header" off hai | Site settings → Appearance → on karo |
| Visitor keh raha hai site nahi khul rahi | Address kisi website se juda nahi hai | Domains → check karo woh address **Live** hai aur sahi website **Serves** kar raha hai |
